PulseFlow 산업용 PC 배포 안내
================================

1) 이 ZIP을 Windows 개발 PC에 복사해 압축 해제합니다.
2) 폴더에서 build_exe.bat 를 더블클릭합니다.
3) 완료되면 아래 파일이 생깁니다.
   - dist\PulseFlow.exe
   - deploy\PulseFlow.exe
   - PulseFlow_deploy.zip
4) PulseFlow_deploy.zip 을 USB로 산업용 PC에 복사합니다.
5) 산업용 PC에서 압축 해제 후 PulseFlow.exe 실행합니다.

산업용 PC 필수 준비
--------------------
- NI-DAQmx Runtime 64-bit 설치 (PulseFlow가 nicaiu.dll 직접 사용)
- NI MAX에서 cDAQ + NI 9264 / 9422 / 9477 모듈 확인
- PulseFlow.exe는 Windows PC에서 build_exe.bat 로 새로 빌드해서 복사
- 실행은 OneDrive/바탕화면보다 C:\PulseFlow 같은 로컬 경로가 빠름
- MP5Y 기본 COM은 COM9 (다르면 설정에서 변경)
- EXE는 Python nidaqmx/numpy 미포함(용량↓, 실행↑)

라벨
----
- AO0 = REF.W
- AO1 = NG PUMP
- I/O TEST = REF.W(AO0) + 밸브 DO0~2 수동시험
- NG PUMP는 메인 화면에서 제어
