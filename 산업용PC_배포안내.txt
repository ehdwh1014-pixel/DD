PulseFlow 산업용 PC 배포 안내
================================

1) 이 ZIP을 Windows 개발 PC에 복사해 압축 해제합니다.
2) 폴더에서 build_exe.bat 를 더블클릭합니다.
3) 완료되면 아래 파일이 생깁니다.
   - dist\PulseFlow.exe
   - deploy\PulseFlow.exe
   - PulseFlow_deploy.zip
4) PulseFlow_deploy.zip 을 USB로 산업용 PC에 복사합니다.
5) 산업용 PC에서 압축 해제 후 PulseFlow.exe 실행합니다.

산업용 PC 필수 준비
--------------------
- NI-DAQmx Runtime 설치 (PulseFlow.exe와 같은 64비트 권장)
- NI MAX에서 cDAQ + NI 9264 / 9422 / 9477 모듈이 보여야 함
- 기본 장치명은 cDAQ2Mod1/2/3 이지만, 새 PC는 cDAQ1Mod1/2/3 일 수 있음
- PulseFlow는 모듈 종류(9264/9422/9477/9214)로 자동 매칭 시도
- 그래도 안 되면 설정에서 채널 문자열을 NI MAX 이름과 맞출 것
- MP5Y USB-RS485 COM 포트 확인 (기본 COM3)

라벨
----
- AO0 = REF.W
- AO1 = NG PUMP
- I/O TEST = REF.W(AO0) + 밸브 DO0~2 수동시험
- NG PUMP는 메인 화면에서 제어
