PulseFlow Industrial PC Deploy Guide
====================================

1) Copy this ZIP to a Windows PC and extract it.
2) Double-click build_exe.bat in the PulseFlow folder.
3) After build, these files are created:
   - dist\PulseFlow.exe
   - deploy\PulseFlow.exe
   - PulseFlow_deploy.zip
4) Copy PulseFlow_deploy.zip to the industrial PC by USB.
5) Extract it on the industrial PC and run PulseFlow.exe.

Industrial PC requirements
--------------------------
- Install NI-DAQmx Runtime 64-bit (same bitness as PulseFlow.exe)
- NI MAX must show cDAQ + NI 9264 / 9422 / 9477 modules
- PulseFlow.exe must be built on a Windows PC with build_exe.bat
  (old EXE missing nidaqmx metadata shows: "nidaqmx import 실패 / 패키지 없음")
- Default device names are cDAQ2Mod1/2/3; PulseFlow auto-maps by module model if needed
- MP5Y USB-RS485 COM port may not be COM3 on a new PC (check Device Manager)

Labels
------
- AO0 = REF.W
- AO1 = NG PUMP
- I/O TEST = REF.W(AO0) + valve DO0~2 manual test
- NG PUMP is controlled on the main UI
