PulseFlow Industrial PC Deploy Guide
====================================

1) Copy this ZIP to a Windows PC and extract it.
2) Double-click build_exe.bat in the PulseFlow folder.
3) After build, these files are created:
   - dist\PulseFlow.exe
   - deploy\PulseFlow.exe
   - PulseFlow_deploy.zip
4) Copy PulseFlow_deploy.zip to the industrial PC by USB.
5) Extract it on the industrial PC and run PulseFlow.exe.

Industrial PC requirements
--------------------------
- Install NI-DAQmx Runtime (same bitness as PulseFlow.exe, usually 64-bit)
- NI MAX must show cDAQ chassis + NI 9264 / 9422 / 9477 modules
- Default device names are cDAQ2Mod1/2/3, but a new PC may use cDAQ1Mod1/2/3
- PulseFlow auto-matches modules by model (9264/9422/9477/9214) when names differ
- If still failing, open Settings and set channel strings to match NI MAX names
- Confirm MP5Y USB-RS485 COM port (default COM3)

Labels
------
- AO0 = REF.W
- AO1 = NG PUMP
- I/O TEST = REF.W(AO0) + valve DO0~2 manual test
- NG PUMP is controlled on the main UI
