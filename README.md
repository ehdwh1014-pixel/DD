# 설비 제어 패널

전동 볼밸브 수동/자동 제어, 물 펌프 운전시간, AO1 전압 지령을 위한 단일 페이지 UI입니다.

## 실행 및 배포

의존성이 없는 정적 HTML입니다. `index.html`을 브라우저에서 열면 **시뮬레이션 모드**로 동작합니다. 실제 설비 출력은 브라우저가 직접 제어하지 않으며, 산업용 PC의 인증된 로컬 I/O 게이트웨이에만 연결해야 합니다.

1. 개발 PC와 산업용 PC 모두에 [VS Code](https://code.visualstudio.com/)의 Windows User Installer를 설치합니다.
2. VS Code에서 이 폴더를 `File > Open Folder`로 엽니다. 미리보기는 `index.html`을 브라우저에서 열거나 Live Server 확장을 사용합니다.
3. 산업용 PC로 전달할 때에는 프로젝트 폴더를 우클릭하여 `Send to > Compressed (zipped) folder`를 선택합니다. PowerShell에서는 다음 명령을 사용할 수 있습니다.

   ```powershell
   Compress-Archive -Path .\industrial-control-ui\* -DestinationPath .\industrial-control-ui.zip -Force
   ```

4. 산업용 PC의 신뢰된 경로에 압축을 풀고, I/O 게이트웨이 주소를 `app.js`의 `API_BASE`에 설정합니다. `file://`에서 직접 열 경우 브라우저 CORS 제약이 있을 수 있으므로, 게이트웨이와 같은 PC에서 HTTP 서버로 제공하는 구성을 권장합니다.

## iG5A: DO RUN + AO 0–5 V = 0–60 Hz

> 이 설정은 **200–230 V 단상 입력 / 3상 200–230 V 출력 iG5A와 3상 유도전동기** 조합에만 해당합니다. 앞서 언급한 VRB8-25 같은 24/48 V Hall BLDC 블로워는 iG5A로 구동할 수 없습니다.

### 배선

```text
산업용 PC AO (0–5 V) +  ── V1       iG5A
산업용 PC AO COM         ── CM

산업용 PC DO ── 절연 릴레이/24 V 인터페이스 ── P1 (정방향 RUN)
제어 공통/방식은 iG5A의 NPN/PNP 선택 스위치와 DO 모듈 사양에 맞춤

단상 200–230 VAC ── R, S       iG5A 입력
3상 유도전동기    ── U, V, W    iG5A 출력
보호접지          ── PE
```

DO가 5 V 로직 출력이면 P1에 직접 연결하지 않습니다. 절연된 24 V 인터페이스 또는 무전압 접점 릴레이를 사용하고, iG5A의 NPN/PNP 선택과 정확한 결선은 해당 사용자 매뉴얼의 제어단자 도면으로 확인합니다. 비상정지, 과압/저수위, 접촉기 및 안전회로는 PC 소프트웨어와 독립된 하드와이어 회로여야 합니다.

### 인버터 파라미터 체크리스트

| 그룹 | 코드 | 설정값 | 목적 |
|---|---|---:|---|
| DRV | `drv` | `1` | 단자대 FX/RX-1 운전 지령 |
| DRV | `Frq` | `3` | V1 0–10 V 아날로그 주파수 지령 |
| I/O | `I17` | `0` | P1 = FX 정방향 RUN |
| I/O | `I18` | `1` 또는 미사용 기능 | P2 = RX; 역회전을 쓰지 않으면 배선하지 말고 역회전 금지 설정 |
| I/O | `I7` | `0.00 V` | V1 최소 입력 |
| I/O | `I8` | `0.00 Hz` | 0 V일 때 주파수 |
| I/O | `I9` | **`5.00 V`** | V1 최대 입력 — AO 범위에 맞춤 |
| I/O | `I10` | **`60.00 Hz`** | 5 V일 때 주파수 |
| FU1 | `F21` | `60.00 Hz` | 최대 주파수 |
| FU1 | `F22` | 모터 명판 주파수 | 보통 60 Hz이나 명판값 우선 |
| FU1 | `F1` | `2` 권장 | 역회전 금지 (부하가 역회전을 허용하지 않을 때) |
| DRV | `ACC`, `dEC` | 부하 검증 후 설정 | 가속/감속 시간 |
| H | `H30` | 모터 명판 kW | 모터 용량 |
| H | `H33` | 모터 명판 A | 전자 과부하 보호 기준 |

`I9=5.00 V`, `I10=60.00 Hz`가 핵심입니다. `Frq=3`만 설정하면 기본값은 0–10 V = 0–60 Hz이므로 5 V에서 30 Hz밖에 나오지 않습니다.

### 실제 연결 전 필요한 정보

- iG5A 정확한 형번(예: `SV004iG5A-1`), 정격 kW 및 정격출력전류
- 연결할 모터의 명판 사진: kW, 전압, 전류, Hz, rpm, 극수
- 산업용 PC DO의 타입/전압/최대전류: 릴레이 접점, NPN, PNP, 5 V TTL 중 무엇인지
- AO의 실제 범위·정확도·절연 여부와 AO COM 기준
- 부하 종류, 최소 안전 운전 주파수, 요구 가속/감속 시간
- 역회전 가능 여부, 비상정지·압력·수위 인터록 배선

처음에는 모터 축과 부하를 안전하게 분리하거나 무부하 조건에서 0 V, 1 V, 2.5 V, 5 V를 순서대로 시험하고, 실제 출력이 0/12/30/60 Hz인지 확인합니다.
